# Triage a product issue

1. Name the product and the customer affected.
2. Rate the severity: P1 if a customer's dashboards are all down, P2 if one feature is broken, P3 for anything else.
3. Assign P1 and P2 to Engineering, and P3 to the support queue.
4. Write one line saying what happened, its severity and who owns it.
